## 📌 API 对比表

| 分类            | 方法           | 作用           | 特点                             |
| :-------------- | :------------- | :------------- | :------------------------------- |
| **增 (Add)**    | `add(x)`       | 添加元素       | 不存在则加入，存在则忽略         |
| **增 (Add)**    | `update(iter)` | 批量添加       | 参数需为可迭代对象 (list, set等) |
| **删 (Delete)** | `remove(x)`    | 删除指定元素   | ❌ 不存在时会**报错**             |
| **删 (Delete)** | `discard(x)`   | 删除指定元素   | ✅ 不存在**不报错** (更安全)      |
| **删 (Delete)** | `pop()`        | 随机删除并返回 | 集合无序，返回结果看似随机       |
| **删 (Delete)** | `clear()`      | 清空集合       | 集合变为空 `set()`               |
| **查 (Check)**  | `x in s`       | 成员判断       | 效率极高 (哈希表实现)            |
| **查 (Count)**  | `len(s)`       | 获取长度       | 返回元素个数                     |

---

## 📌 总结对比

| 特性           | set（可变集合） | frozenset（不可变集合） |
| -------------- | --------------- | ----------------------- |
| **可变性**     | ✅ 可修改        | ❌ 不可修改              |
| **有序性**     | ❌ 无序          | ❌ 无序                  |
| **重复性**     | ❌ 不允许        | ❌ 不允许                |
| **增删改**     | ✅ 支持          | ❌ 不支持                |
| **是否可哈希** | ❌ 不能作为 key  | ✅ 可作为 key            |
| **集合运算**   | ✅ 支持          | ✅ 支持                  |

---

## 1️⃣ set（可变集合）

```python
S = {1, 2, 3}
print("初始 set:", S)

# 增
S.add(4)               # 添加单个元素
print("add:", S)
S.update([5, 6])       # 批量添加多个元素
print("update:", S)

# 删
S.remove(4)            # 删除指定元素（不存在时报错）
print("remove:", S)
S.discard(100)         # 删除指定元素（不存在不报错）
print("discard:", S)
print("pop:", S.pop(), "剩余:", S)  # 删除并返回任意元素
S.clear()              # 清空集合
print("clear:", S)

# 查
S = {1, 2, 3}
print("2 in S:", 2 in S)
print("len:", len(S))
```

## 2️⃣ frozenset（不可变集合）

```python
FS = frozenset([3, 4, 5])
print("frozenset:", FS)
# FS.add(6) ❌ AttributeError: 'frozenset' object has no attribute 'add'
```

## 3️⃣ 集合运算

```python
a = {1, 2, 3}
b = {3, 4, 5}
print("union |:", a | b)            # 并集
print("intersection &:", a & b)    # 交集
print("difference -:", a - b)      # 差集
print("symmetric_difference ^:", a ^ b)  # 对称差集
```
