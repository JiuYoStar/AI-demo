# Python vs JavaScript 类 (Class) 核心映射指南

## 一、 基础语法：显式 vs 隐式

这是最直观的差异。Python 强调“显式”，而 JavaScript 追求“简洁”。

| 功能 | Python (显式) | JavaScript (隐式) |
| --- | --- | --- |
| **定义** | `class Name:` | `class Name { ... }` |
| **构造函数** | `def __init__(self, x):` | `constructor(x) { ... }` |
| **实例引用** | `self` (形参必写) | `this` (隐式注入) |
| **实例化** | `p = Person()` | `p = new Person()` |
| **继承** | `class Child(Parent):` | `class Child extends Parent { ... }` |

### 💡 模式对比

```python
# Python: self 必须传来传去
class Counter:
    def __init__(self, val):
        self.count = val

    def add(self):  # 必须写 self
        self.count += 1

# JS: this 自动存在
class Counter {
    constructor(val) {
        this.count = val;
    }
    add() {  # 不需要写参数
        this.count++;
    }
}

```

## 二、 对象操作：函数式 vs 直接式

在处理属性的动态增删改查时，两者的哲学完全不同。

* **Python (严格/函数式)**：倾向于使用内置函数。
* **JavaScript (灵活/对象式)**：倾向于像操作普通的 `Object` 一样操作类。

| 动作 | Python 模式 | JavaScript 模式 |
| --- | --- | --- |
| **设置** | `setattr(obj, 'k', v)` | `obj.k = v` |
| **获取** | `getattr(obj, 'k')` | `obj.k` |
| **检查** | `hasattr(obj, 'k')` | `'k' in obj` |
| **删除** | `delattr(obj, 'k')` | `delete obj.k` |

## 三、 魔法能力：重载 vs 原型

这是区分初级和高级开发者的关键。**Python 的类可以“伪装”成任何东西。**

### 1. Python 的“百变怪”模式

Python 通过魔法方法实现**运算符重载**。

* **想变序列？** 实现 `__len__` 和 `__getitem__`。
* **想变函数？** 实现 `__call__`。
* **想变数字？** 实现 `__add__` (重载 `+`)。

### 2. JavaScript 的“原型链”模式

JS 的行为相对固定，不支持大部分运算符重载。

* **唯一相似点**：迭代器。Python 用 `__iter__`，JS 用 `[Symbol.iterator]`。
* **动态拦截**：Python 在类里写 `__getattr__`；JS 必须在类外包一层 `new Proxy()`。

---

## 四、 进阶差异点 (MRO 与 Static)

### 1. 继承深度

* **Python**: 支持**多重继承** `class C(A, B)`。使用 MRO 算法解决冲突。
* **JS**: 严格**单继承**。如果要复用多个类，只能用 `Mixins` 模式（手动合并原型）。

### 2. 静态方法

* **Python**: `@classmethod` (传类本身) vs `@staticmethod` (纯函数)。
* **JS**: 只有一个 `static`，表现更接近 Python 的静态方法。

## 五、 快速查阅伪代码

```python
### Python 进阶模式 ###
class SmartArray:
    def __len__(self): return 10
    def __getitem__(self, i): return i * 2
    def __call__(self): print("I am called")

arr = SmartArray()
print(len(arr))  # 触发 __len__
arr()            # 触发 __call__

```

```javascript
/// JavaScript 进阶模式 ///
class SmartArray {
    // JS 不支持 len() 重载，通常直接定义属性
    length = 10;
    // JS 不支持 [] 重载，必须用 Proxy
    static create() {
        return new Proxy(new SmartArray(), {
            get: (target, prop) => prop * 2
        });
    }
}

```
