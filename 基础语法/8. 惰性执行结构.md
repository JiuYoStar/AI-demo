## 惰性生成器

**核心思想** 不到万不得已,不去执行,类似yield

- `range()`：最经典的惰性序列，无论范围多大，占用的内存几乎恒定。
- `map(func, iterable)`：只有在迭代时才会对元素执行 `func`。
- `filter(func, iterable)`：迭代时才判断元素是否符合过滤条件。
- `zip(*iterables)`：并行迭代多个可迭代对象，按需产生元组。
- `enumerate(iterable)`：按需生成索引和值的元组。
- `reversed(seq)`：返回一个反向迭代器，而不改变原序列。

## 1️⃣ range

```python
r = range(1, 10, 2)
print("range 对象:", r)
print("list(range):", list(r))  # [1, 3, 5, 7, 9]
```

---

## 2️⃣ map

```python
m = map(lambda x: x*2, [1,2,3])
print("map 对象:", m)
print("list(map):", list(m))  # [2, 4, 6]
```

---

## 3️⃣ filter

```python
f = filter(lambda x: x%2==0, [1,2,3,4])
print("filter 对象:", f)
print("list(filter):", list(f))  # [2, 4]
```

---

## 4️⃣ zip

```python
z = zip([1,2], ["a","b"])
print("zip 对象:", z)
print("list(zip):", list(z))  # [(1,'a'), (2,'b')]
```

---

## 5️⃣ 迭代器 (iter / next)

```python
it = iter([10,20,30])
print("iter 对象:", it)
print("next:", next(it))  # 10
print("next:", next(it))  # 20
```

---

## 6️⃣ 生成器 (yield)

```python
def gen():
    for i in range(3):
        yield i*i

g = gen()
print("生成器对象:", g)
print("list(generator):", list(g))  # [0,1,4]

yield from [1, 2, 3]
# 等价于
for x in [1, 2, 3]:
    yield x
```

---

## 7️⃣ itertools 模块

```python
import itertools

c = itertools.count(10, 2)
print("itertools.count 对象:", c)
print("next:", next(c))  # 10
print("next:", next(c))  # 12

cyc = itertools.cycle(["A","B"])
print("next cycle:", next(cyc))  # A
print("next cycle:", next(cyc))  # B

sl = itertools.islice(range(100), 5, 10)
print("islice 对象:", sl)
print("list(islice):", list(sl))  # [5,6,7,8,9]
```
