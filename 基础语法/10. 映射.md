## �️ 映射 (dict) API 汇总表

### 1. 核心 CRUD 操作

| 分类        | 方法 / 语法                 | 说明              | 示例 / 备注                                 |                |
| :-------- | :---------------------- | :-------------- | :-------------------------------------- | -------------- |
| **创建**    | `{}` / `dict()`         | 字面量或构造函数创建      | `d = {'a': 1}`                          |                |
|           | `dict.fromkeys(seq, v)` | 以序列为键创建，值全为 `v` | `dict.fromkeys('abc', 0)`               |                |
| **查**     | `d[key]`                | 直接取值            | **注意**：key 不存在会抛出 `KeyError`            |                |
|           | `d.get(k, default)`     | 安全取值            | ✅ **推荐**，key 不存在返回 `default` (默认为 None) |                |
|           | `k in d`                | 成员判断            | 判断 key 是否在字典中                           |                |
| **增 / 改** | `d[k] = v`              | 赋值              | key 存在则覆盖，不存在则新增                        |                |
|           | `d.update(other)`       | 批量更新            | 合并另一个字典或键值对序列                           |                |
|           | `d.setdefault(k, v)`    | 获取并设置默认         | ✅ **常用**，k 不存在则设为 `v` 并返回 `v`；存在则返回原值   |                |
|           | `d1 \| d2` (3.9+)       | 合并字典            | 返回新字典                               |                |
|           | `d1 \|= d2` (3.9+)      | 原地更新            | 效果等同于 `update`                     |                |
| **删**     | `d.pop(k, default)`     | 删除并返值           | ✅ **推荐**，删除指定 k 并返回值；不存在返回 `default`    |                |
|           | `d.popitem()`           | 删最后一位           | 删除并返回最后一对 `(k, v)`                      |                |
|           | `del d[k]`              | 删除键             | 直接从字典中移除                                |                |
|           | `d.clear()`             | 清空全部            | 原地清空所有元素                                |                |

### 2. 视图与遍历 (只读)

| 方法           | 返回内容  | 说明                                 |
| :----------- | :---- | :--------------------------------- |
| `d.keys()`   | 键视图   | `dict_keys(['a', 'b'])`            |
| `d.values()` | 值视图   | `dict_values([1, 2])`              |
| `d.items()`  | 键值对视图 | `dict_items([('a', 1), ('b', 2)])` |
| `len(d)`     | 长度    | 返回键值对数量                            |

### 4. 进阶技巧 (推荐尝试)

- **字典推导式**：快速创建字典。

```python
d = {x: x**2 for x in range(5)} # {0:0, 1:1, 2:4...}
```

- **计数器简化** (使用 `defaultdict`)：

```python
from collections import defaultdict
d = defaultdict(int) # 访问不存在的 key 默认返回 0，无需先判断 in
d["count"] += 1
```

## 1️⃣ 创建

```python
d = {"a": 1, "b": 2}
d2 = dict(c=3, d=4)
d3 = dict([("e", 5), ("f", 6)])

# 1. 使用字符串：每个字符都会变成一个 key
s1 = dict.fromkeys('abc', 0)
# {'a': 0, 'b': 0, 'c': 0}

# 2. 使用列表：推荐方式，key 可以是长字符串
s2 = dict.fromkeys(['name', 'age', 'gender'], 'N/A')
# {'name': 'N/A', 'age': 'N/A', 'gender': 'N/A'}

# 3. 使用集合：自动去重
s3 = dict.fromkeys({'apple', 'banana', 'apple'}, 10)
# {'apple': 10, 'banana': 10}

# 错误示范
d = dict.fromkeys(['a', 'b'], [])
d['a'].append(1)
print(d)
# 结果是 {'a': [1], 'b': [1]} ！！！  因为 'a' 和 'b' 共享同一个列表对象

# 独立列表方案
keys = ['a', 'b', 'c']
d = {k: [] for k in keys}
d['a'].append(1)
# 结果：{'a': [1], 'b': [], 'c': []} 互不干扰
# 带逻辑的生成
d = {f"user_{i}": 0 for i in range(3)}
# {'user_0': 0, 'user_1': 0, 'user_2': 0}
```

## 2️⃣ 增 & 改

```python
d["x"] = 10              # 新增或修改
d.update({"y": 20})      # 批量更新
# 常用作初始化
d.setdefault("z", 99)    # 如果 key 不存在就设置，存在则不变
```

---

## 3️⃣ 删

```python
d.pop("a")               # 删除并返回指定 key 的值，不存在时报错
d.pop("notfound", None)  # 不存在返回默认值
d.popitem()              # 随机删除并返回一个 (key, value) 对
del d["b"]               # 删除指定 key
d.clear()                # 清空字典
```

---

## 4️⃣ 查

```python
print(d["x"])            # 取值，key 不存在时报错
print(d.get("x"))        # 取值，不存在返回 None
print(d.get("no", 0))    # 取值，不存在返回默认值
```

---

## 5️⃣ 遍历

```python
for k in d.keys():       # 遍历 key
    print(k)

for v in d.values():     # 遍历 value
    print(v)

for k, v in d.items():   # 遍历 (key, value)
    print(k, v)
```

## 6️⃣ 复制

```python
d2 = d.copy()            # 浅拷贝
```

len(d)                   # 字典长度
