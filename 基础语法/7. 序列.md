# 🐍 Python Sequences（序列）

## 1️⃣ list（列表） [1, 2, 3]

```python
lst = [1, 2, 3]
print("初始:", lst)

# 增
lst.append(4)  # 在末尾追加一个元素
print("append:", lst)
lst.insert(1, 99)  # 在指定索引位置插入（前插）
print("insert:", lst)
lst.extend([5,6])  # 在末尾批量追加（后插）
print("extend:", lst)

# insert → “在某个位置插一个”
# extend → “在末尾展开多个”

# 删
lst.remove(99)  # 删除指定值
print("remove:", lst)
x = lst.pop()   # 删除并返回最后一个元素
print("pop 返回:", x, "剩余:", lst)
del lst[0]      # 删除指定索引
print("del:", lst)
lst.clear()     # 清空列表
print("clear:", lst)

# 改
lst = [1, 2, 3]
lst[0] = 100  # 修改指定索引的值
print("改:", lst)

# 查
print("index(2):", lst.index(2))  # 查找值对应的索引
print("count(3):", lst.count(3))  # 统计出现次数
print("len:", len(lst))           # 长度
print("2 in lst:", 2 in lst)      # 是否存在某个值

# 排序 & 反转
lst = [3, 1, 4, 2]
lst.sort()   # 升序排序（原地修改）
print("sort 升序:", lst)
lst.sort(reverse=True)  # 降序排序
print("sort 降序:", lst)
lst.reverse()  # 反转顺序
print("reverse:", lst)
```

## 2️⃣ tuple（元组） (10, 20, 30)

```python
t = (1, 2, 3)
print("初始:", t)

# 查
print("索引 t[0]:", t[0])
print("index(2):", t.index(2))
print("count(3):", t.count(3))
print("len:", len(t))
print("2 in t:", 2 in t)
```

## 3️⃣ range（范围） range(5)

```python
r = range(1, 10, 2)
print("初始 range:", r)

print("list(r):", list(r))
print("len(r):", len(r))
print("3 in r:", 3 in r)
print("start:", r.start, "stop:", r.stop, "step:", r.step)
```

`range` 最多支持 **3 个参数**：

```python
range(start, stop, step)
```

* **1 个参数**：`range(stop)`

  * 默认 `start = 0`，`step = 1`
  * 示例：`range(5)` → `[0,1,2,3,4]`

* **2 个参数**：`range(start, stop)`
  -> 包含 start，不包含 stop
  * 默认 `step = 1`
  * 示例：`range(2, 6)` → `[2,3,4,5]`
  
* **3 个参数**：`range(start, stop, step)`

  * 示例：`range(1, 10, 2)` → `[1,3,5,7,9]`

⚠️ 注意：

* `step` 不能为 0，否则会报错 `ValueError: range() arg 3 must not be zero`。
* 可以是负数，比如 `range(10, 0, -2)` → `[10, 8, 6, 4, 2]`。

## 📌 总结对比

| 特性        | list  | tuple     | range       |
| --------- | ----- | --------- | ----------- |
| **可变性**   | ✅ 可修改 | ❌ 不可修改    | ❌ 不可修改      |
| **有序性**   | ✅     | ✅         | ✅           |
| **索引/切片** | ✅     | ✅         | ✅           |
| **增删改**   | ✅     | ❌         | ❌           |
| **是否可哈希** | ❌     | ✅（若元素可哈希） | ✅           |
| **用途**    | 动态存储  | 固定集合      | 序列生成（循环/索引） |
## 🛠️ 常用 API 汇总表

### 通用操作 (所有序列)
| 方法 | 说明 | 示例 |
| :--- | :--- | :--- |
| **长度** | `len(seq)` | `len([1,2])` -> `2` |
| **成员判断** | `x in seq` | `1 in (1,2)` -> `True` |
| **索引** | `seq[i]` | `lst[0]`, `lst[-1]` |
| **切片** | `seq[start:stop:step]` | `lst[::-1]` (反转) |
| **计数** | `seq.count(val)` | 统计 `val` 出现的次数 |
| **查找索引** | `seq.index(val)` | 查找 `val` 第一次出现的索引，找不到报错 |

### 列表特有 (可变操作)
| 方法 | 说明 | 对应 JS |
| :--- | :--- | :--- |
| **追加** | `lst.append(x)` | `push(x)` |
| **插入** | `lst.insert(idx, x)` | - |
| **扩展** | `lst.extend(iterable)` | `concat()` 或 `push(...arr)` |
| **移除并返回** | `lst.pop([idx])` | `pop()` |
| **按值删除** | `lst.remove(val)` | - |
| **原地排序** | `lst.sort()` | `sort()` (注意 PY 默认升序且不转字符串) |
| **原地反转** | `lst.reverse()` | `reverse()` |

### 范围特有 (range)
| 属性 | 说明 |
| :--- | :--- |
| `r.start` | 开始值 |
| `r.stop` | 结束值 (不包含) |
| `r.step` | 步长 |
